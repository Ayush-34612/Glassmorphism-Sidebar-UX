# 📱 Glassmorphism Sidebar UI

A high-performance, responsive navigation sidebar built using **Pure CSS3** and **HTML5**. This project implements the "Checkbox Hack" to manage component state without relying on JavaScript.

## ✨ Technical Highlights
*   **Pure CSS State Management:** Utilizes the `:checked` pseudo-class and General Sibling Combinators (`~`) for logic.
*   **Glassmorphism Aesthetic:** Implements backdrop transparency and soft shadows for a modern feel.
*   **Responsive Design:** Uses `vh` units and relative positioning for a consistent experience across viewports.
*   **Optimized Performance:** Zero JS overhead leads to faster load times and smoother animations.

## 📂 Project Structure
* `index.html` - Primary entry point and semantic structure.
* `style.css` - Stylesheet containing layout, transitions, and hover logic.
* `photo.jpg` - Background image asset.
